## Patterns Covered

### Arrays
- Prefix Sum
- Running Minimum (Greedy)
- Kadane's Algorithm (Maximum Subarray)
- Prefix × Suffix Product (no division)
- In-place modification (Slow-Fast index)

### Two Pointers
- Opposite Direction (Valid Palindrome, Two Sum II)
- Fast/Slow index (Move Zeroes)

### Sliding Window
- Fixed Window
- Variable Window + HashMap

### HashMap
- Complement Pattern (Two Sum)
- Frequency Map (Anagram, Repeating Character)
- Prefix Sum + HashMap (Subarray Sum = K)

### Stack
- LIFO using ArrayDeque
- Matching / Validation Pattern
- Monotonic Decreasing Stack

### Binary Search
- Standard Template
- Modified BS on Rotated Array (search target)
- Modified BS on Rotated Array (find minimum)
- Binary Search on Answer Space
- Integer Ceiling Formula: (a + m - 1) / m

### Linked List
- Iterative Reversal (prev/curr/temp)
- Dummy Head Pattern
- Fast/Slow Pointers — Cycle Detection (Floyd's)
- Fast/Slow with n+1 gap — Positional Removal

### Trees
- DFS Postorder (bottom-up result building)
- Simultaneous DFS on two trees
- DFS Preorder (top-down swap)
- DFS with global result variable (diameter, path sum)
- BFS Level Order (Queue + level size snapshot)
- BFS Right Side View (peek after level completes)

### Heap / Priority Queue
- Min-Heap of size K (K largest elements)
- Min-Heap with custom comparator (order by frequency)

### Backtracking
- Include/Exclude decision tree (Subsets)
- Swap-based permutation (in-place undo)
- Combination Sum (reuse allowed, include=same index)
